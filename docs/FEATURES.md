# The Long Dark Survival Toolkit — feature reference

The Long Dark Survival Toolkit groups resource records, route planning, and session notes in a single workspace. Each section keeps its controls and related settings together.

| Section | Description |
|---|---|
| Resource records | Inventory and resource categories organized alongside their related values and notes. |
| Route planning | Route stages, transport context, and the notes associated with each part of the journey. |
| Session notes | Session and activity information grouped by the task or context it belongs to. |

The project page follows the same section structure.
